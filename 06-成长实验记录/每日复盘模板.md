# 顶帅每日复盘模板

复制本模板到自己的笔记里填写。建议每天5—10分钟完成。

**日期：** YYYY-MM-DD  
**实验第几天：** D__  
**今天可支配时间：** __分钟

|---|---|---:|---|
| 认知 | | | 未开始/进行中/完成 |
| 霸之意志 | | | |
| 财富 | | | |
| AI外脑 | | | |
| 自我管理 | | | |

## 三句复盘
1. **今天最有价值的行动：**
2. **我原本相信、但今天开始怀疑的判断：**
3. **明天只做一件事，它是：**

## 证据与反思
- 公开可分享的成果链接（可选）：
- AI参与了哪部分？人工核验了什么？
- 遇到的障碍：
- 明天要删减的低价值任务：
- 心态/精力（自愿填写，不做健康诊断）：

> 规则：没有完成就写没有完成，不为了连续打卡制造成绩。注意保护个人隐私。
